## 📌 About The Project

The **University Course Management System** is a relational database project developed using **MySQL**. It is designed to manage students, departments, courses, instructors, and student enrollments.

This project demonstrates both **basic and advanced SQL concepts** through 16 practical tasks.

---

## 🗂️ Database Structure

| Table               | Purpose                              |
| ------------------- | ------------------------------------ |
| 🏢 `Departments`    | Stores department information        |
| 👨‍🎓 `Students`    | Stores student details               |
| 📚 `Courses`        | Stores available courses             |
| 👨‍🏫 `Instructors` | Stores instructor details and salary |
| 📝 `Enrollments`    | Connects students with courses       |

### 🔗 Relationships

```text
Departments
   │
   ├── Courses
   │      │
   │      └── Enrollments ─── Students
   │
   └── Instructors
```

## 📋 Project Tasks

| Task | Description                                        |
| ---- | -------------------------------------------------- |
| 1    | CRUD Operations on all tables                      |
| 2    | Students enrolled after 2022                       |
| 3    | Courses offered by Mathematics                     |
| 4    | Courses having more than 5 students                |
| 5    | Students enrolled in both SQL & Data Structures    |
| 6    | Students enrolled in either SQL or Data Structures |
| 7    | Average course credits                             |
| 8    | Maximum Computer Science instructor salary         |
| 9    | Students enrolled in each department               |
| 10   | INNER JOIN – Students & Courses                    |
| 11   | LEFT JOIN – All Students & Courses                 |
| 12   | Subquery – Courses with more than 10 students      |
